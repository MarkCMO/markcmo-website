### 3. Use the env-var bulk-copy script for any new project

`scripts/cf-env-push.py` was committed in `6dcf90ac9` — it reads

### 4. Domain cutover (separate task — explicitly out of runbook scope)

For any mirrored site you want to make CF-primary:
- Add custom domain in CF Pages dashboard
- Update DNS to point to CF (apex Cloudflare DNS, CNAME flatten)
- Verify CF SSL active before pulling DNS from Netlify

Netlify stays live throughout — DNS is the only switch.
