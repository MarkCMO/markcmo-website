The Punch List

A shared checklist so nothing stalls the launch. Cirilo provides access and assets; WETYR provides the paperwork and the plan.

Work through this together at closing and finish anything outstanding within five business days. The few Day-0 must-haves below are what we need before the build can begin; the rest can follow during the first week. Send credentials through a secure method (a shared password manager invite or an encrypted note), never plain email.

Day-0 must-haves (start the build)
  • Wix admin access (or contributor invite to WETYR)
  • Google Business Profile access (or permission to create and verify)
  • NC General Contractor license number
  • Google Ads + Meta access with a payment method on file (or approval to create them)
  • Accounting contact to receive WETYR invoices (paid by ACH or wire)
