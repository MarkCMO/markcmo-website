## To convert these HTML files to PDFs

Open in any browser. File > Print > Save as PDF. The CSS includes a print stylesheet that strips shadows, removes scroll, breaks pages cleanly at section boundaries, and renders the brand identity correctly on letter-size paper.

## Brand system used

All client-facing materials use Cirilo's actual brand identity, pulled from cirilodb.com:

- **Primary gold (dark):** `#AB7E37`
- **Secondary gold (champagne):** `#D6BB89`
- **Accent cream:** `#E3D3B2`
- **Cream background:** `#FAF7F2`
- **Ink (headlines):** `#1A1A1A`
- **Body:** `#2E2E34`
- **Headings:** Cormorant Garamond (serif, matches Cirilo wordmark)
- **Body:** Inter (clean modern sans)
- **Metadata / numbers:** DM Mono (monospaced)
- **Wordmark treatment:** rose-gold gradient that matches the actual Cirilo logo gradient

Materials feel like Cirilo's own brand, not Mark's. This is intentional. The client sees their brand reflected in the proposal, which reduces cognitive load and increases the perception that Mark already understands them.
